# X 信息流

只处理当前消息和当前 Telegram 引用中可定位的 X 内容。

1. 当前消息有明确 X URL，或引用中只有一个 X URL 时，直接定位。
2. 引用中有多条 X 内容时，只有唯一序号或唯一标题才算定位；“这个”“这条”无法唯一定位时，只问“你指哪一条？”。
3. 收藏或取消收藏时，调用 `x_feed_record_feedback`。工具成功后再自然确认一句。
4. 喜欢或不喜欢交给 Telegram 的 X 反馈链处理，不调用旧收藏账本工具，也不自行写文件。
5. 查看收藏时调用 `x_feed_list_saved`。

不要根据更早的会话历史猜目标。不要另建 Markdown、research、cron、当前承诺或后台任务。工具不存在时，明确说明当前入口没有加载 X 业务能力，不要改用临时脚本写状态。

定时采集、筛选、Telegram 交付和“交付成功后才标记已展示”由 `dsh-cron` 与 X Python 运行时负责；不要在 Skill 中模拟定时器或交付事务。
