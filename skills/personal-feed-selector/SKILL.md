# 个人 Feed 选择器

1. 准备 `personalContext.longTermInterests`、`personalContext.existingUnderstanding` 和候选的原文 URL、正文。只使用当前对话或可靠个人语境中已经成立的信息；不要猜测用户关注或已有认识。
2. 候选不完整时先取得原文 URL 和足以判断信息增量的正文。不要用标题、摘要或自己的改写代替原文内容。
3. 调用 `personal_feed_select_attention` 一次。不要预筛掉可能与用户有关的候选，也不要用自己的判断覆盖工具结果。
4. 按结果原样收口：
   - `completed/selected`：只返回工具给出的原文 URL。
   - `completed/empty`：说明这批内容里没有足够信息增量、值得占用稀缺名额的对象；不要补替代推荐。
   - `failed`：说明这次判断没有完成；可以给出稳定失败码，但绝不能说成“没有值得读的内容”。

不要输出摘要、理由、评分、候选排名或多条链接。不要抓取新候选、学习或写回用户画像，也不要调用旧版 Feed 实现补结果。
